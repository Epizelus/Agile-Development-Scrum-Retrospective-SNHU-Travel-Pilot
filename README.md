# Agile Development & Scrum Retrospective: SNHU Travel Pilot

## Project Overview
This repository contains a Sprint Review and Retrospective for the SNHU Travel booking application pilot. The project served as a practical implementation of Agile methodologies and the Scrum framework, transitioning away from a traditional waterfall development model. The attached retrospective analyzes how distinct Scrum roles, transparent communication, and organizational tools (like Kanban boards and user stories) contributed to the successful, iterative delivery of software despite mid-development scope changes.

## Core Competencies & Reflections

### Interpreting User Needs and User Stories
Interpreting user needs requires breaking down broad, abstract requests into functional, testable units of work. Creating "user stories" is essential for this process because it forces the team to frame every feature from the end-user's perspective (the "Who, What, and Why"). Instead of just writing code based on a technical specification, user stories ensure the development process stays entirely focused on delivering tangible value to the client.

### Development Approach and Agile Processes
My approach to developing programs centers on iterative progress rather than trying to build the entire architecture perfectly on the first try. Working in the Unity Engine for independent game and software development has shown me the immense value of rapid prototyping and iterative testing. Moving forward, I plan to incorporate Agile processes like time-boxed sprints and Sprint Retrospectives into all my work. Evaluating what works and what doesn't at regular intervals prevents getting bogged down in dead-end features and keeps development moving forward efficiently.

### Being a Good Team Member
Being a good team member in software development goes far beyond just writing clean code in isolation. It means communicating transparently, helping to remove blockers for others, and taking shared ownership of the final product. Serving as the Vice President of the Carroll Terrace Resident Authority has reinforced how crucial it is to listen to a community, align on shared goals, and advocate for collective success. That same leadership translates directly to a development team—keeping everyone informed, leaving egos at the door, and ensuring the whole team crosses the finish line together.
